{{- /* Application Bar (§12): the context line of the current page. The session belongs to the visitor, not to the owner — §11.1 is explicit that `owner@…` is the wrong default, and §11.2 that `whoami` must answer with the current user rather than with Alexandr's biography. So the prompt says `guest` and the command says what the page is: the small vocabulary of §11.3 — `library`, `read`, `play` — and nothing invented beyond it. A reader lowers the shell's voice (§12, §19): no `guest@host` prefix, just the command and a way back. On a phone the full prompt does not fit and is not attempted; the bar becomes «← library» plus the material's own title. #dc-clock is empty markup only: optional progressive enhancement fills it with the *visitor's own* local clock.
